A tiny program built for the make.fun bounty
[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

Running `main.ts` (Node 22) writes one sentence to `/output/entry.txt` —
a pitch for a friend who has never coded, to let an AI agent on make.fun
build their first app idea. It speaks to the months they've already spent
carrying the idea around, makes handing it over sound easy (describe it
in plain words), and lowers the risk to nothing: a working first version
they can actually try, no coding needed, nothing to lose.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Two runs produce byte-identical output. No network, no dependencies.
